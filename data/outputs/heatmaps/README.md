# Heatmaps Output Directory

This directory stores heatmap visualizations generated by the Eye-LLM system.

## Types of Heatmaps

1. **Visit Frequency Heatmap**: Shows how many times each exhibit was visited
   - File pattern: `visit_heatmap_YYYYMMDD_HHMMSS.png`

2. **Dwell Time Heatmap**: Shows total time spent at each exhibit
   - File pattern: `duration_heatmap_YYYYMMDD_HHMMSS.png`

3. **Attention Distribution**: Bar chart of attention level distribution
   - File pattern: `attention_dist_YYYYMMDD_HHMMSS.png`

## Usage

Heatmaps are generated using the `HeatmapVisualizer` class:
```python
from skills.visualization import HeatmapVisualizer

visualizer = HeatmapVisualizer(topology_engine)
visualizer.plot_visit_heatmap(visit_counts, output_path="data/outputs/heatmaps/visit_heatmap.png")
```
